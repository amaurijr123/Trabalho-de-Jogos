# Sokopato

Sokoban simples feito apenas com Pygame. Controle o pato e empurre todas as
caixas para os ninhos amarelos.

## Como executar

Na raiz do projeto, com o ambiente do Pygame ativo:

```powershell
python Trab2/main.py
```

## Controles

- Setas ou `WASD`: movimentar
- Clique esquerdo em uma célula vizinha: movimentar
- `U`, Backspace ou botão **Desfazer**: desfazer
- `R` ou botão **Reiniciar**: reiniciar o nível
- `Enter`, `N` ou clique no painel de vitória: próximo nível
- `Esc`: sair
